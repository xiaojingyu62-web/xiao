## 2. 研究问题

多节点传感器采集系统在实际部署中面临三类典型故障：节点失联（断电/死机）、传感器异常（接线脱落、读数卡死、超量程）和通信中断（总线断开、持续丢包）。仅靠"采集成功、上传成功、页面显示成功"无法证明系统的可靠性，节点故障往往只能靠人工巡检发现，检测延迟长且不可量化。本课题在 STM32 + FreeRTOS 多节点采集系统之上，设计一套包含心跳超时、数据合理性检查、通信质量统计三类判据的在线故障监测机制，每类判据给出阈值取法与依据。通过人为注入故障（不少于 2 类、每类不少于 10 次）定量评价故障检测时间、误报率、漏报率，并同时测量通信时延、丢包率与任务响应时间，从而回答"该机制能否在给定检测延迟与误报约束下可靠地发现节点/传感器/通信故障"。

## 5. 技术路线

详见 `docs/01-topic/technical_route.md`。概要：

```
[采集节点×2~3]  FreeRTOS: 采集任务 / 通信任务 / 自检任务
      │  RS485 总线（半双工差分，主从轮询）
[汇聚节点]      汇聚 + 心跳/丢包统计 + 故障判据上报
      │  USB 串口
[上位机]        数据管理(存储/展示) + 故障注入时间标记 + 检测时间统计
```

三类判据：①心跳超时（节点失联）②数据合理性检查（超量程/恒值/跳变，传感器故障）③通信质量统计（滑窗丢包率超限，通信故障）。每类阈值写明取法与依据。
